# Day 01 - Big O Notation

## What is Big O?

Big O notation describes how the running time or space
of an algorithm grows as the input size increases.

## Common Complexities

- O(1) - Constant
- O(log n) - Logarithmic
- O(n) - Linear
- O(n log n) - Linearithmic
- O(n²) - Quadratic

## Today's Goal

Understand basic time and space complexity.
